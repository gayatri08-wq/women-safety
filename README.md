# Women Safety

A simple web app designed to help women stay safe, access emergency assistance quickly, and keep trusted contacts informed.

## Features
- Emergency call button
- Share current location
- Trusted contacts list
- Safety tips dashboard
- Quick incident logging

## Run locally
1. Open `index.html` in a browser, or
2. Serve the folder with a local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project files
- `index.html` – App layout
- `style.css` – Modern responsive design
- `script.js` – Emergency and location logic

## Safety note
This project is a prototype for awareness and quick access to emergency features. For real-world use, integrate with trusted services and legal emergency systems in your region.
